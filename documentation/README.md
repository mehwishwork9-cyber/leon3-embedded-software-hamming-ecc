# Project Documentation

Embedded Software Development and Hamming Error Correction project.

The report covers:
- LEON3 SPARC V8 architecture
- BCC2 cross-compilation and TSIM simulation
- Dhrystone performance benchmarking
- Hamming(31,26) error correction
- C code optimisation
- GitLab CI/CD workflows
